# Сайт «Спина без боли»

Готовая папка для публикации. Весь сайт это `index.html`, остальное служебные файлы.

## Что где
- `index.html`: главная страница (картинки встроены в файл)
- `og.jpg`: превью для ссылок в Telegram и соцсетях
- `favicon.svg`, `apple-touch-icon.png`: иконки
- `offer.html`, `privacy.html`: шаблоны оферты и политики. Заполните данные в [квадратных скобках] и удалите жёлтую пометку «Шаблон» и строку `noindex`
- `robots.txt`, `sitemap.xml`: для поисковиков

## Публикация без своего домена (GitHub Pages)
1. На github.com создайте репозиторий (например `spina`), Add file → Upload files, перетащите все файлы из этой папки (не саму папку), Commit.
2. Settings → Pages → Source: Deploy from a branch, ветка `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-НИК.github.io/spina/`.
4. В файлах `index.html`, `robots.txt`, `sitemap.xml` замените `https://YOUR-DOMAIN.com` на этот адрес без слэша в конце (например `https://ник.github.io/spina`). Без этого не заработает превью ссылки в Telegram. Правка прямо на GitHub: открыть файл → значок карандаша → Commit.
5. Заполните оферту и политику (данные в [квадратных скобках]), удалите жёлтую пометку «Шаблон» и строку `noindex`.

Совет: если назвать репозиторий `ВАШ-НИК.github.io`, адрес будет короче: `https://ВАШ-НИК.github.io/`.

Позже можно подключить свой домен: Settings → Pages → Custom domain, и заменить адрес в тех же файлах.

## После запуска
- Яндекс Вебмастер и Google Search Console: добавьте сайт и отправьте `sitemap.xml`.
- Вставьте код счётчиков в `index.html` на место комментария «Счётчики» в `<head>`.
- Проверьте превью ссылки: отправьте адрес себе в Telegram.
